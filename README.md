# BOOSTSELLER SEO AEO GEO Proposal

This repository contains the source for a presentation and proposal package about SEO, AEO, and GEO services for BOOSTSELLER.kz and related product directions.

## Contents

- `src/` — JavaScript presentation builders for desktop and mobile layouts;
- `assets/` — presentation media and brand assets;
- `output/` — generated PDF deliverables;
- `anamai.md` — product and portfolio positioning copy;
- `docs/` — planning notes.

## Technology

- Node.js JavaScript modules;
- `@oai/artifact-tool` presentation primitives;
- Skia Canvas rendering;
- generated PDF output;
- local bitmap assets and structured slide composition.

## Archive note

The repository is reconstructed from the May 2026 working directory. Temporary previews, downloaded reference material, runtime bundles, and unrelated local caches are excluded.
